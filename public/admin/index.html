Connect the Ang & Koh site in Decap Turbo to enable staff login.

  1. Create a free Turbo account using the intended editor’s email.
  2. Connect GitHub and select only QuintonPang/ahsk-static-website.
  3. Create a site for this repository, using the main branch and public/admin/config.yml as the config path.
  4. Set the admin interface URL to https://quintonpang.github.io/ahsk-static-website/admin/.
  5. Copy the site ID from Turbo into public/admin/settings.json in the repository and commit the change.
